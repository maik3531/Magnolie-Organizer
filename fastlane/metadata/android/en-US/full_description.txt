Magnolie Notes is a local notebook and task list for Android. Organize notes in notebooks, attach images or PDF files, and import text shared by other apps.

Features:
* Notes with creation and modification dates, notebooks and attachments.
* Tasks with due dates, priorities and optional reminders.
* Import shared text and supported exported note files.
* Local encrypted storage and user-controlled backups.
* Optional encrypted sharing with paired Magnolie Organizer installations on Linux and Windows.
* Twenty interface languages.

No account or cloud service is required to use the notebook. Network and phone integration features are optional and require the corresponding pairing or Android permissions. Magnolie Organizer is a separate, free desktop application.

Magnolie extracts a subset of region metadata into the generated phone metadata
block in anwendung.js using werkzeuge/phone_metadata.py. The browser normalizer
is Magnolie code, not a vendored full libphonenumber JavaScript library. Metadata
and notices are local package assets; no CDN or runtime download is required.

# Security / Sicherheit

## English

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting for this repository. Include the affected version, platform, impact
and a minimal reproduction when possible. Do not include real personal data,
private keys or credentials.

Security support currently covers the latest published versions:

- Magnolie Organizer 2.0.x
- Magnolie Notes 1.0.x
- Magnolie Handbook 2.0.x

## Deutsch

Vermutete Sicherheitslücken bitte über GitHubs vertrauliche
Sicherheitsmeldung für dieses Repository einreichen. Wenn möglich, betroffene
Version, Plattform, Auswirkung und eine minimale Reproduktion angeben. Keine
echten persönlichen Daten, privaten Schlüssel oder Zugangsdaten mitsenden.

Sicherheitsunterstützung gilt derzeit für die neuesten veröffentlichten Fassungen:

- Magnolie Organizer 2.0.x
- Magnolie Notes 1.0.x
- Magnolie-Handbuch 2.0.x

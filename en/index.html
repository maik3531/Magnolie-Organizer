Good to know

A few questions?

Is Magnolie free?

Yes. Magnolie Organizer is available free of charge. Program and handbook sources are licensed under GPL-3.0-or-later; some bundled resources retain their own license terms.

How does sharing between devices work?

Magnolie offers optional encrypted exchange with paired devices. Magnolienbaum can exchange approved content over a local network, VPN or a configured remote endpoint. Check the project documentation for setup and supported features.

Can I bring existing data?

The project describes import options for calendars, vCards, Lotus Organizer data and common note exports. Check your specific format and the handbook guidance before moving your collection.

Is the Android app the same organizer?

Magnolie Notes is a separate companion for notes and tasks with additional optional integrations. It has its own feature set and is not an identical version of the desktop application.

Webstrona so přez GitHub Pages spřistupnja. Při wotwołanju dóstawa GitHub technisce trěbne daty zwiska, mjez nimi twoju IP-adresu a informacije wo požadanej dataji. 3. Funkcije webstrony a zasadźene medije

Kod webstrony žane cookieje njestaja, njewužiwa Local Storage abo podobne swójske trajne składowaki wobhladowaka a žane slědowanske elementy za analyzu abo wabjenje njewobsahuje. Njeje žana registracija ani kontaktny formular.

Wobrazy, wideja, podtitule, stilowe łopjena a JavaScript so přez samsny hosting GitHub Pages začituja. Cuze widejowe wothrawaki, eksterne posłužby pismow a widgety socialnych medijow njejsu zasadźene. Tež začitanje widejowych metadatow a wothrawanje wideja k wotwołanjam pola poskićerja hostingu wjedźe.

Tłóčatko za dźělenje kopěruje hakle po twojim kliknjenju přihotowany tekst z adresu strony do mjezyskłada. Njewučita hižo wobstejace wobsahi mjezyskłada a tekst žanej socialnej posłužbje njeposrědkuje. Tłóčatko za ćišćenje wočini ćišćersku funkciju twojeho wobhladowaka.

Při wotwołanju powšitkowneje startoweje adresy wuběra skript na zakładźe preferowanych rěčow, kotrež su we wobhladowaku nastajene, hodźacy k dispoziciji stejacy rěčny wstup. Wuraznje wubrana rěčna adresa ma přednost. Wuběr so w twojim wobhladowaku přewjedźe a so žanej přidatnej posłužbje njeposrědkuje. Za to žane cookieje njestajam a rěčny wuběr ani w Local Storage ani w druhim trajnym składowaku wobhladowaka njeskładuju.

2. Alojamiento mediante GitHub Pages

El sitio web se sirve mediante GitHub Pages. Al acceder a él, GitHub recibe los datos de conexión técnicamente necesarios, entre ellos tu dirección IP e información sobre el archivo solicitado. GitHub confirma que registra y almacena direcciones IP por motivos de seguridad, incluso sin haber iniciado sesión en GitHub. Consulta la información de GitHub sobre la recopilación de datos en Pages.

El alojamiento tiene como finalidad la disponibilidad fiable y la seguridad de este sitio web. La prestación técnica que organizo se basa en estos intereses legítimos conforme a Art. 6 Abs. 1 Buchst. f DSGVO. El sitio web no puede servirse sin transmitir los datos necesarios para la conexión.

GitHub identifica como proveedores a GitHub B.V., Prins Bernhardplein 200, 1097 JB Amsterdam, Niederlande, y GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA. Los datos también pueden tratarse en Estados Unidos y en otros países. Para las transferencias correspondientes, GitHub describe, entre otros mecanismos de protección, las cláusulas contractuales tipo de la UE.

GitHub no indica un plazo fijo de supresión de los datos de conexión de Pages en la información enlazada. Según GitHub, la conservación depende de la finalidad del tratamiento y de las obligaciones legales. La declaración de privacidad de GitHub contiene más información sobre destinatarios, transferencias y conservación; su contacto para cuestiones de privacidad es privacy@github.com.

3. Funciones del sitio web y medios integrados

El código del sitio web no instala cookies, no utiliza Local Storage ni otros mecanismos propios comparables de almacenamiento persistente en el navegador y no contiene rastreadores analíticos ni publicitarios. No hay registro ni formulario de contacto.

Las imágenes, los vídeos, los subtítulos, las hojas de estilo y JavaScript se cargan a través del mismo alojamiento de GitHub Pages. No hay reproductores de vídeo de terceros, servicios externos de fuentes ni widgets de redes sociales integrados. La carga de metadatos de vídeo y la reproducción de vídeos también generan solicitudes al proveedor de alojamiento.

El botón para compartir solo copia al portapapeles un texto preparado con la dirección de la página cuando haces clic en él. No lee el contenido existente del portapapeles ni transmite el texto a ningún servicio social. El botón de impresión abre la función de impresión de tu navegador.

Al acceder a la dirección general de inicio, un script utiliza los idiomas preferidos configurados en el navegador para seleccionar una página de entrada disponible en un idioma adecuado. Una dirección de idioma elegida expresamente tiene prioridad. La selección se realiza en tu navegador y no se envía a ningún servicio adicional. No instalo cookies para ello ni guardo la selección de idioma en Local Storage ni en ningún otro almacenamiento persistente del navegador.

4. Enlaces a otros proveedores

Algunas descargas, códigos fuente, vías para enviar comentarios y fuentes de prensa están enlazados en otros sitios web. Si accedes a una de esas páginas de destino, su proveedor trata los datos de conexión y, en su caso, otros datos según sus propios avisos de privacidad. Dependiendo del navegador y de su configuración, también puede transmitirse la página de procedencia.

Los enlaces no integran automáticamente estos contenidos o servicios externos en la página de Magnolie. Encontrarás la información legal sobre los enlaces en el aviso legal.

6. Tus derechos

En las condiciones previstas por la ley, tienes derecho de acceso, rectificación, supresión, limitación del tratamiento y portabilidad de los datos (Art. 15–20 DSGVO).

Oposición: Cuando un tratamiento se base en Art. 6 Abs. 1 Buchst. f DSGVO, puedes oponerte a él por motivos relacionados con tu situación particular (Art. 21 DSGVO). Para ello, utiliza el contacto indicado más arriba.

También puedes presentar una reclamación ante una autoridad de control de protección de datos, en particular en el Estado miembro de tu residencia habitual, de tu lugar de trabajo o del lugar de la supuesta infracción (Art. 77 DSGVO).

En el marco de este sitio web, no tomo decisiones basadas únicamente en tratamientos automatizados que produzcan efectos jurídicos o de importancia similar, ni realizo la correspondiente elaboración de perfiles.

3. 网站功能与嵌入媒体

本网站的代码不设置 Cookie，不使用 Local Storage 或类似的自有持久性浏览器存储，也不包含分析或广告跟踪器。网站没有注册功能，也没有联系表单。

图片、视频、字幕、样式表和 JavaScript 均通过同一 GitHub Pages 托管服务加载。网站没有嵌入第三方视频播放器、外部字体服务或社交媒体组件。加载视频元数据和播放视频也会向托管服务商发出请求。

只有在你点击分享按钮后，它才会将包含页面地址的预设文本复制到剪贴板。它不会读取剪贴板中已有的内容，也不会将文本发送给社交服务。打印按钮会打开浏览器的打印功能。

访问网站的通用入口地址时，脚本会根据浏览器设置的首选语言，选择合适的可用语言入口。明确选择的语言地址优先。选择过程在你的浏览器中完成，不会发送至额外的服务。我不会为此设置 Cookie，也不会将语言选择保存到 Local Storage 或其他持久性浏览器存储中。

这些链接不会自动将相应的外部内容和服务嵌入 Magnolie 页面。有关这些链接的法律说明，见法律声明。

Privacidade

Estes avisos dizem respeito às visitas ao site Magnolie. O armazenamento local de dados na aplicação Magnolie instalada é separado deste âmbito.

1. Responsável pelo tratamento

Eu, Maik Walter, sou responsável por este site. A minha morada postal consta do aviso legal. Se tiveres questões sobre a proteção de dados, podes escrever para maik3531@gmail.com.

2. Disponibilização através do GitHub Pages

O site é disponibilizado através do GitHub Pages. Ao acederes ao site, o GitHub recebe os dados de ligação tecnicamente necessários, incluindo o teu endereço IP e informações sobre o ficheiro solicitado. O GitHub confirma que regista e armazena endereços IP para fins de segurança, mesmo sem uma sessão iniciada no GitHub. Consulta as informações do GitHub sobre a recolha de dados no Pages.

O alojamento destina-se a assegurar a disponibilização fiável e a segurança deste site. A disponibilização técnica que organizo assenta nestes interesses legítimos, nos termos de Art. 6 Abs. 1 Buchst. f DSGVO. O site não pode ser disponibilizado sem a transmissão dos dados necessários à ligação.

O GitHub identifica como fornecedores GitHub B.V., Prins Bernhardplein 200, 1097 JB Amsterdam, Niederlande, e GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA. Os dados também podem ser tratados nos Estados Unidos e noutros países. Para as transferências em causa, o GitHub descreve, entre outros mecanismos de proteção, as cláusulas contratuais-tipo da UE.

O GitHub não indica um prazo fixo de apagamento dos dados de ligação do Pages nas informações apresentadas nas ligações. Segundo o GitHub, a conservação depende da finalidade do tratamento e das obrigações legais. A declaração de privacidade do GitHub contém mais informações sobre destinatários, transferências e conservação; o contacto aí indicado para a proteção de dados é privacy@github.com.

3. Funcionalidades do site e conteúdos multimédia incorporados

O código do site não define cookies, não utiliza Local Storage nem outro armazenamento persistente próprio e comparável no navegador e não contém rastreadores de análise ou publicidade. Não existe registo nem formulário de contacto.

As imagens, os vídeos, as legendas, as folhas de estilo e o JavaScript são carregados através do mesmo alojamento do GitHub Pages. Não estão incorporados leitores de vídeo de terceiros, serviços externos de tipos de letra ou widgets de redes sociais. O carregamento de metadados de vídeo e a reprodução de um vídeo também originam pedidos ao fornecedor de alojamento.

O botão de partilha só copia para a área de transferência um texto preparado com o endereço da página quando clicas nele. Não lê o conteúdo já existente na área de transferência nem envia o texto para um serviço social. O botão de impressão abre a função de impressão do teu navegador.

Ao acederes ao endereço geral da página inicial, um script utiliza os idiomas preferidos configurados no navegador para selecionar uma página de entrada disponível num idioma adequado. Um endereço de idioma escolhido expressamente tem prioridade. A seleção é feita no teu navegador e não é enviada a um serviço adicional. Não defino cookies para este efeito nem guardo a seleção de idioma no Local Storage ou noutro armazenamento persistente do navegador.

4. Ligações para outros fornecedores

Algumas transferências, códigos-fonte, meios de envio de comentários e fontes de imprensa estão acessíveis através de ligações para outros sites. Ao acederes a uma dessas páginas de destino, o respetivo fornecedor trata dados de ligação e, se aplicável, outros dados segundo os seus próprios avisos de privacidade. Dependendo do navegador e das definições, também pode ser transmitida a página de origem.

As ligações não incorporam automaticamente estes conteúdos ou serviços externos na página Magnolie. As informações legais sobre as ligações constam do aviso legal.

5. Contacto por correio eletrónico

Se me escreveres, trato o teu endereço de remetente, a tua mensagem e os dados que nela forneceres voluntariamente para responder ao teu pedido. A base jurídica é Art. 6 Abs. 1 Buchst. f DSGVO; o meu interesse legítimo é responder a questões sobre o projeto. Sem um endereço de remetente através do qual te possa contactar, não posso responder.

A caixa de correio indicada utiliza Gmail. Neste contexto, a Google trata mensagens e dados de ligação. O fornecedor para utilizadores no Espaço Económico Europeu é Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Irland. É possível o tratamento fora do Espaço Económico Europeu. A Google indica para esse efeito mecanismos de adequação, incluindo o Quadro de Privacidade de Dados UE-EUA, e, quando estes não se aplicam, cláusulas contratuais-tipo. A declaração de privacidade da Google e as informações sobre transferências internacionais de dados explicam este aspeto em mais detalhe e indicam um contacto para obter cópias das cláusulas.

A correspondência é apagada assim que deixe de ser necessária para tratar o pedido e eventuais questões subsequentes. Ressalvam-se as obrigações legais de conservação e a conservação necessária para a declaração, o exercício ou a defesa de um direito num processo judicial.

6. Os teus direitos

Nas condições previstas na lei, tens direitos de acesso, retificação, apagamento, limitação do tratamento e portabilidade dos dados (Art. 15–20 DSGVO).

Oposição: Quando um tratamento se baseie em Art. 6 Abs. 1 Buchst. f DSGVO, podes opor-te por motivos relacionados com a tua situação particular (Art. 21 DSGVO). Para isso, utiliza o contacto indicado acima.

Também podes apresentar uma reclamação a uma autoridade de controlo de proteção de dados, em particular no Estado-Membro da tua residência habitual, do teu local de trabalho ou do local da alegada infração (Art. 77 DSGVO).

No âmbito deste site, não tomo decisões baseadas exclusivamente em tratamentos automatizados que produzam efeitos jurídicos ou efeitos de importância semelhante, nem realizo a correspondente definição de perfis.

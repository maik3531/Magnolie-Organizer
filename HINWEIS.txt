Version 2.0.17 behebt den mindestens seit 2.0.15 vorhandenen Adressbuchhänger
durch eine begrenzte Speicherbestätigung. Sie ergänzt einen nativen
Ersteinrichtungsassistenten, Aufgabenhierarchie einschließlich CalDAV-VTODO,
allgemeines CalDAV/CardDAV (Baïkal ist nur ein Beispiel eines kompatiblen
Servers), sichere optionale Kontaktimporte und eine vorsichtige Ermittlung der
Anrufherkunft. Gesamtarchive verwenden Datenschema 3 und internes Datenmodell 7;
Personal Sync unterstützt die Formate 1 bis 3. Die neuen Texte sind in den 19
unterstützten Übersetzungen berücksichtigt. Magnolie Notes 1.0.13 übernimmt
diese Android-Änderungen mit einer erhöhten Paketversion.

Am 5. September 2026 bestand der aktuelle Quellstand den vollständigen
Desktop-Releasebau einschließlich QEMU-autopkgtest, DEB-Upgrade- und
Installationstests, Fedora-42-RPM-Bau und -Installation, AppImage-Prüfung unter
Ubuntu 22.04 und Arch Linux sowie Flatpak-Bau und -Prüfung. Das Android-
Releasegate bestand Unit-, Lint-, Signatur-, Upgrade-, Start- und
Instrumentationstests in einem dedizierten API-35-AVD. Der Windows-Bau bestand
Core-, Web-, Paritäts-, Quellarchiv- und Installer-Audits als markierter,
unsignierter Linux-Cross-Build. Eine native Windows-Laufzeitprüfung und
Authenticode-Signatur liegen nicht vor. Die Darstellungskorrektur für
MATE/NVIDIA ist durch Regressionstests abgedeckt, aber auf dem ursprünglich
betroffenen System noch nicht visuell bestätigt.

Version 2.0.17 fixes the address-book hang present since at least 2.0.15 by
bounding the final persistence acknowledgement. It adds a native first-run
assistant, task hierarchy including CalDAV VTODO, generic CalDAV/CardDAV
support (Baïkal is only an example of a compatible server), safe optional
contact imports, and conservative incoming-call origin reporting. Total
archives use data schema 3 and internal data model 7; Personal Sync supports
formats 1 through 3. The new text is covered by the 19 supported translations.
Magnolie Notes 1.0.13 includes these Android changes with an incremented package
version.

On September 5, 2026, the current source passed the complete desktop release
build, including QEMU autopkgtest, DEB upgrade and installation tests, Fedora
42 RPM build and installation, AppImage checks on Ubuntu 22.04 and Arch Linux,
and Flatpak build and validation. The Android release gate passed unit, lint,
signature, upgrade, launch, and instrumentation tests in a dedicated API 35
AVD. The Windows build passed core, web, parity, source archive, and installer
audits as a marked unsigned Linux cross-build. Native Windows runtime validation
and Authenticode signing remain unavailable. Regression tests cover the
MATE/NVIDIA rendering correction, but it has not yet been visually confirmed
on the originally affected system.
